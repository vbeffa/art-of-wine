# Art of Wine Tasting Sheets

A mobile-friendly guide to 35 wines across seven tasting flights.

## First Version

- `index.html`: phone-friendly flight and wine browser, reading the Markdown files directly
- `INDEX.md`: seven flights with five wine links each
- `flights/`: individual tasting sheets; missing and outdated sources are explicitly marked
- `TEMPLATE.md`: reusable sheet template
- `VERIFICATION.md`: research findings and remaining uncertainties

The first version is a working draft. Some details remain unverified. Four entries are missing or outdated source sheets. Do not treat these as finalized wine descriptions.

## Viewing And Publishing

The Markdown index and individual files can be read directly on GitHub from the working branch. To use the interactive mobile interface, host the repository on an HTTP web server. GitHub's source-file preview does **not** execute `index.html` as a website. GitHub Pages is not yet enabled, and this repository is private. Confirm account eligibility and desired public/private access before enabling a deployment. No source photographs are distributed in the site.

## Editing

Update the Markdown file for a wine to change its displayed information. The website loads those files on demand, so the content stays synchronized. Keep unavailable technical details labeled rather than inferred. Check the source photographs and online audit before treating details as verified.
