# Art of Wine tasting sheets

Standardized tasting sheets organized by wine flight.

## Status

Source photographs are being transcribed into individual Markdown sheets. All information should be attributed to the supplied source sheet; missing details remain unspecified rather than inferred. Sheets are drafts until reviewed against their photographs.

## Structure

- `TEMPLATE.md`: standard format for each wine
- `flights/`: one directory per flight, with individual wine sheets
- `INDEX.md`: flight inventory and review status

## Publishing

GitHub Pages publication is not configured. The repository is currently private; check plan and visibility requirements before enabling public publishing. Review transcription accuracy and image rights before publishing source photographs or producer-provided copy.
